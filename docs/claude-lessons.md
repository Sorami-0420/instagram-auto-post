# 注意点とノウハウ集(Claudeが会話の最初に読む資料 ②)

過去の失敗・つまずきの記録。同じ間違いを繰り返さないために使う。公開リポジトリに置くため、キーやIDは含めない。作業の手順は、スキル `add-photo-story` / `check-posted` / `handle-failure` にある。

## A. そらみさんとの進め方
- プログラミングは初心者。ターミナルやFinderの用語も1つずつ説明し、コマンドは1つずつコードブロックに入れる(説明文と混ざると貼り間違えるため)
- 画面の言葉を取り違えやすい(例: スプレッドシートのメニューは「数値」ではなく「数字」)。スクリーンショットで確認してから案内する
- スクリーンショットで状況を共有してくれる。推測で進めず、画面を見せてもらってから判断する
- 安定性を重視する人。自動化の案を出すときは「壊れやすさ(非公式のしくみ、仕様変更、審査)」を並べて書き、基本は確実な方を勧める
- 細かい調整を短い往復で何度も頼まれる。説明を長くせず、直して確認の手順を添える。範囲を勝手に広げない
- できないこと・確認できていないことは、正直に言う。調べて分かった事実と推測は分けて書く(確認不足のまま「公開だけ手動でできる」と言って訂正した前例がある)
- 秘密情報の確認コマンドは、値を表示しない形(長さや行数だけ)にする。実行結果にキーが出て漏れそうになった前例がある。貼られてしまったら、すぐ無効化して作り直すよう案内する
- 「撮影場所」が説明的な言葉(例:「秋を感じられる場所」)のときは、「〇〇へ」ではなく「〇〇でひと休みしてきました」のように助詞を合わせる(プロンプトに反映済み)
- Xの2文目のデザイン説明は、写真で確実に分かる形・色・光だけ。羽根・三日月などの具体的な形、素材名(銀・金)、色名(赤・オレンジ)、石の粒を「実」に見立てる表現は書かない(太陽型を「羽根と三日月」と書き、複数色の石を全部「赤い石」と書いた前例がある。素材は見た目から断定できない)

## B. 取り消せない操作
- 実際のInstagram投稿(`test_mode: false` の実行、`TEST_MODE` の変更)は、投稿すると取り消せないので、本人の確認を取ってから行う
- 失敗した処理は、原因が分かるまで手動で再実行しない(二重投稿になるため)。まず「何も投稿されていないか」を確認する
- `posts/` と `stories/` の画像・動画は、Instagramが取得するため公開される。公開してよいものだけを置く

## C. 技術的な落とし穴(実際に起きたもの)
- **GitHubの変数 `TEST_MODE`**: 作られていないと、自動実行は常にテストモード(`true`)で動き、投稿されない。「Run workflow」の `test_mode` 入力欄は、毎回デフォルトが `true`で、変数とは別物(本番の手動投稿は、入力欄を `false` にする)。変数は Settings → Secrets and variables → Actions → **Variables** タブ(Secretsではない)
- **自動実行は、毎時0分を避ける。** 毎時0分はGitHubが混雑して遅れる・実行が捨てられることがある(2026-10-04の20:00の予定が、翌0:56の投稿になった)。時刻を足すときは、予定時刻の少し後に実行を足す。予定時刻の前の実行では投稿されない。Macの電源は不要
- **Instagramのアクセストークンには期限がある**(約60日)。最後に作り直したのは2026-09-30。切れると投稿がエラーになるので、**2026年11月下旬までに更新を案内する**(手順は `docs/setup.md` のSTEP 4と6。新しいトークンは、本人が自分のブラウザ内だけで扱い、チャットには貼らせない)
- **Googleスプレッドシートが一時的に503を返す**ことがある。再試行の仕組み(`scripts/sheets_retry.py`)はある。それでも何も処理されなかったときは、次の自動チェックか手動実行で処理される
- **macOSのファイル名はNFD(分解形)、スプレッドシートの文字はNFC(合成形)。** 見た目が同じでも一致しない。商品名との照合は、NFCに揃える(`unicodedata.normalize("NFC", ...)`)
- **テストモードは「投稿済みフラグ」を変えない。** `エラー` になった行は、人がフラグを空欄に戻さないと再処理されない。投稿日が未来の行は、テストモードでも処理されない
- **画像ファイル名が空欄だと、投稿日になっても投稿されず「画像読み込みエラー」になる。** 写真は `add_photo.command` で追加する
- **AIは文字数の指示を守れないことがある。** 守らせたいルールは、出力を機械的に検査し、違反があれば文言を変えずに直させる形にする(`rewrap_if_needed`)
- **Claude APIでWeb検索ツールを使うときは、`max_tokens` を大きくする(8000)。** 小さいと本文が空で返る
- スマホのInstagramは、1行目の先頭にアカウント名が付く。1行目は15文字以内、それ以外は28文字以内にする
- **Safariの翻訳機能が、日本語の表示を書き換えることがある。** 文章がおかしく見えたら、投稿を消す前に、アドレスバーの「文A」マークで翻訳をオフにして確かめる
- ローカルには `anthropic` が入っていない。動作確認は偽物(スタブ)に差し替えて行う。`grep` で `(^^)` のような記号を探すときは `-F` を付ける

## D. 作ったがうまくいかなかったもの(同じ道を繰り返さない)
