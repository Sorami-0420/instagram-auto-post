# ショップの落とし穴(Claudeが会話の最初に読む資料 ①)

公開リポジトリに置くため、パスワード・キー・IDは含めない(IDは `docs/private/ids.md`)。商品の最新情報の正本は、Googleスプレッドシートと、BASE/コマースマネージャーのカタログ。数字の記録は、スキル `review-metrics` にある。

## ショップの前提
- 天然石のハンドメイドのピアス/イヤリング。ブランドのテーマは「太陽と月」。素材はステンレスまたはロジウム
- アカウント名は「耳とピアス図鑑 Sorami」。コンセプトは「フォロワーさんの耳&アクセサリーと共にいろんな所へ」。写真に写る耳(ディスプレイ用)は「フォロワーさんの耳」を表し、つけた姿を想像してもらうのが狙い
- 耳のディスプレイは、YouTubeで「耳の横でASMR・解説をする」企画につなげるための意図的な構図(2026-10-06に相談)。Instagramで「耳が目立つ」「ピアスに目が行きにくい」と言われたが、耳はやめない。方針: ①耳たぶのまわりのアップなど、ピアスが大きく見える構図にする(次の撮影から、そらみさんが考える。反応は基準の数字と比べる) ②初めて見た人向けに「はじめに」(耳とピアス図鑑って何?)の投稿の固定(ピン留め)と、ストーリーズのハイライトを用意する(そらみさんが文章を考える)。この自動投稿は写真1枚ずつで、複数枚(スワイプ)には未対応
- 販売はBASE。Instagramのプロフィールのリンクから商品ページへ誘導している
- 経歴(プロフィールより): 天然石ショップでの接客販売5年以上、天然石アクセサリー認定講師

## 商品を書くときの落とし穴
- 商品は両耳用(2個で1ペア)。「一つ」「一粒」のように単品として書かない(実態と違うため)
- 「太陽と月」はブランド全体のテーマで、全商品のモチーフではない。商品名や写真から読み取れるときだけ「太陽」「月」と書く(太陽ではない商品を「太陽のピアス」と書いた前例がある)
- 石の名前は、スプレッドシートの「使用石」列が正本。内包物(レピドクロサイト・ルチル等)は「内包物」列が正本で、空欄なら鉱物名を創作しない(間違った説明を公開してしまうため)
- 「撮影場所」列は、そらみさんが意図して書いた言葉。場所を特定されたくないため、実際と違う言葉のこともある。間違いと決めつけず、そのまま使う
- 写真の元ファイルは `~/Pictures/フィード投稿用/` に置き、ファイル名は商品名と同じにする(自動で行を探すため)
- ストーリーズ用の動画は縦型(1080×1920)の6〜15秒。編集はCapCutで毎回手動(自動化は見送り)

## 発信とキャプション
- フィード投稿は2〜3日おき、基本は20:00。ストーリーズは週2回ほど
- キャプションの文体・ルールの正本は `scripts/caption_generator.py` の `SYSTEM_PROMPT`(YouTube用は `scripts/youtube_text_generator.py`)。ルールを変えるときは、コードの方を直す。この資料に写さない(二重管理で食い違うため)
- 石の効果・意味は断定せず、伝聞で書く。石の歴史は、Web検索で調べてから書く
- Xの投稿文は、石の名前を本文に書かず、ハッシュタグにだけ使う。商品名は例外で、一字も変えず2文目に入れる
- Xは既存の `@sorami_stones` を使う。自動化(未実装)に進む前に、Xの料金と自動投稿アカウントの規約を、もう一度確認する
- YouTubeはショート動画(縦型)。アップロードは手動(理由は `claude-lessons.md` のD)

## YouTubeの企画(2026-10-06に相談して決めた方針)
- 作る人向け(ワイヤーアクセサリーの作り方)から、買いたい人向けのASMRに変える。ハンドメイドの作り手は少ないので、「ASMRが好きな人」という大きな枠から連れてくる狙い
- チャンネルは2つに分ける。①今のチャンネル(登録者761人): ストーリーズ用の動画を、ショートとして流用する ②新しいチャンネル: 耳のディスプレイの横で録るASMR動画(例: 川辺の動画)。名前は未定で、「Sorami ASMR|耳とピアス」に何か言葉を足す案(「ASMR」は英字で入れる)
- 本数の目標: ショート月4本以上、長尺月1本
- 60秒の動画の型: 速い切り替え5秒 → 長い音10秒 → 間2秒 → 速い11秒 → 長い10秒 → 間3秒 → 速い11秒 → 長い8秒(速い=1〜2秒ごとに音を変える。長い=約10秒じっくり聞かせる。間=静けさ・ささやき)
- 撮り方: 音ごとに短く撮り、ファイル名に種類(速・長・間)を付ける。編集はこの型に沿って自動で組み立てる予定(試作はこれから)。最後に、そらみさんが修正を入れられる形にする(切り出しの一覧を直して作り直す/切り出した1つ1つの動画をCapCutに入れて直す)。文字の見た目は簡素でよい
- 買う人向けの動画では、ピアスが大きく見える回も必要(川遊びの動画では、ピアスは小さくしか映らない)
