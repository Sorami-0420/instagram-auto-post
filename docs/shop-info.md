## 2. 商品について

- 商品は**両耳用のピアス(2個で1ペア)**。ピアス/イヤリングの両方を選べる商品もある。「一つ」「一粒」のように単品であるかのように書かない
- 商品名は、詩的で情景が浮かぶ日本語の名前(例: 「水辺の木漏れ日」「太陽の道しるべ」「落ち葉に眠る月」「秋陽に輝くガーネット」「記憶に揺れる茜月」「葉音に応ふる月影」「青空映す蛍石」「風と遊ぶ空色シャボン」「褪せぬ思い出」)
- コマースマネージャーのカタログには、商品コード付きの名前の商品がある(例: `A06 ラピスラズリ 月ピアス/イヤリング`、`B02 ルチルクォーツ 太陽ピアス/イヤリング`)。価格帯は2,500〜3,500円ほど
- **「太陽と月」はブランド全体のテーマであって、全商品のモチーフではない。** 商品名や写真から読み取れる場合だけ「太陽」「月」「三日月」などと書く(過去に「太陽のピアスではないのに太陽のピアスと書かれた」ことがある)
- 使用石の名前はスプレッドシートの「使用石」列、石の中の鉱物(例: レピドクロサイト、ヘマタイト、ルチル)は「内包物」列が正本。**内包物が空欄なら鉱物名を創作しない**

## 3. 写真・動画

- 写真は、耳の形のディスプレイスタンドにピアスを付け、屋外(石畳、水路、緑など)で自然光で撮ったもの。台座に水晶などの石が置かれていることが多い
- 写真の元ファイルは `~/Pictures/フィード投稿用/` に置く。**ファイル名は商品名と同じにする**(自動で行を探すため)
- ストーリーズ/ショート用の動画は、縦型(1080×1920)の6〜15秒ほど。編集はMacのCapCutで、毎回手動で行う(自動化は見送り)

## 4. 発信の方針

- フィード投稿: 2〜3日おきに1件ほど。投稿時刻は20:00が基本(夜に見られやすい時間帯のため)
- ストーリーズ: 週2回ほど、20:00〜21:00台。**同じ日にフィード投稿がある日は投稿しない**(システムが自動でスキップする)
- キャプションの文体・ルールの**正本は `scripts/caption_generator.py` の `SYSTEM_PROMPT`**(YouTube用は `scripts/youtube_text_generator.py`)。主なルール:
  - やさしく丁寧で温かみのある文体。一人称は「わたし」。押しつけがましい宣伝口調にしない
  - 読点「、」は使わない。句点「。」は文末につける(顔文字をつける文だけは句点なし)
  - 絵文字は使わない。顔文字は `･*+` と `✳︎` だけ(`(^^)` と `･:*+.\(( °ω° ))/.:+` は使わない)
  - 石の効果・意味は断定せず「〜と言われています」のように伝聞にする。**石の意味以外(情景描写やデザインの説明)は言い切ってよい**
  - 石の歴史・言い伝えは、Web検索で調べてから書く。1つだけ選んで書く(羅列しない)
  - 「かたわら」「一粒」という言葉は使わない
  - 本文は4文構成。ハッシュタグは4個まで(YouTubeの説明文は3〜4個、`#Shorts` は付けない)。**InstagramとYouTubeには、毎回「#耳とピアス図鑑」を入れる**(アカウント名のタグ。投稿をシリーズとしてまとめるため。入っていなければ自動で足される)。Xには入れない。「#Vlog」は内容と合わないので付けない
  - スマホで1行に収まるのは28文字まで。**Instagramの1行目だけは15文字以内**(スマホでは先頭にアカウント名が付くため)
  - 着用シーンの提案は、行き先だけでなく服装(着物・シックな服)や気分(落ち込んだ日)の切り口も使う
  - **すべての投稿(Instagram・X・YouTube)の1文目は、「フォロワーさんの耳と〇〇へ行ってきました」という旅の記録の形にする。** 〇〇はスプレッドシートの「撮影場所」列に書かれた言葉。空欄なら場所の名前は書かず、写真に写っているものだけを描写する。新しい文は足さず、文の数と長さは変えない
  - 「こんな場面に似合う」という着用シーンの提案の文は、販売につなげるため残す(旅の記録とは役割が違う)
  - **Xの投稿文では、石の名前を本文に書かず、ハッシュタグにだけ使う**(ハッシュタグは最大3個、石の名前を最優先)。本文の2文目は、写真に写っているデザインの紹介にする
  - 場所の種類(公園・海・川など)は、写真から確信できなければ断定しない。写っているもの(木々・緑・落ち葉・光・石の台など)だけを描写する
