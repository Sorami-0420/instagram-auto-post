# 数字の振り返り

数字は少ないので、傾向は参考程度。断定せず、「推測」と「確認できたこと」を分けて伝える。

## 手順
1. そらみさんに、下の「見る場所」の画面をスクリーンショットで見せてもらう
2. 下の記録(基準)と比べ、増えたもの・減ったものを短くまとめる
3. 新しい数字は、日付つきで、この資料の末尾に書き足す(書く前に「資料に残します」と伝える)
4. 次に見る時期を決める

## 見る場所
- Instagram: プロフェッショナルダッシュボード → インサイト。ストーリーズごとの「次へのタップ」「離脱」は、ストーリーズを開いて下から上にスワイプ
- BASE: 「データ」画面と「流入経路」
- YouTube: YouTube Studio →「アナリティクス」→「コンテンツ」の「ショート」

## 予定
- 2〜4週間後(2026年10月下旬〜11月上旬)に、Instagramのインサイトと、BASEの流入経路を見て、基準と比べる
- 2026年11月上旬は、YouTubeのショートの数字をよく見る(新しいピアスのショートの視聴回数、見つけられ方と検索の言葉、視聴を継続の割合、登録者の増え、BASEへのYouTube流入)
- 専用の「SNS運用係」エージェントは、数字が貯まってから考える。最初は、声をかけたときだけ動く形にする(自動で動かす形は壊れやすいため)
- **Xの自動化に進む目安(2026-10-05に相談)**: 2〜4週間手動で続けて、BASEの流入経路にXからの来訪が出てきたとき、または手動の投稿が負担になったとき。進める前に、Xの料金(以前の調査では、投稿1件が約0.015ドル、URL付きは約0.20ドル)と、自動投稿アカウントの規約を、もう一度確認する。Xは `@sorami_stones`(2026-10-03時点で投稿0件、2026-10-04に手動投稿を開始)
