# 失敗したときの手順

原因が分かるまで、手動で再実行しない(二重投稿になるため。投稿は取り消せない)。

1. 実行履歴で失敗した実行の「post」→「Run posting script」のログを、そらみさんにスクリーンショットで見せてもらう
2. 何も処理されずに止まったのか、途中まで投稿されたのかを判断する。Instagramのプロフィールも見てもらう
3. 原因を直す
4. 必要なら `test_mode: false` で手動実行する。**実行前に、そらみさんに確認する**(「Run workflow」の `test_mode` は毎回デフォルトが `true` なので、本番のときは `false` にする)

## よくある原因
- `エラー` になった行は、人がフラグを空欄に戻さないと再処理されない
- トークンの期限切れ(約60日。手順は `docs/setup.md` のSTEP 4と6。新しいトークンはチャットに貼らせない)
- スプレッドシートの一時的な503(再試行の仕組みはある。何も処理されなければ次の自動チェックで処理される)
- 画像ファイル名の空欄、投稿日が未来の行(`docs/claude-lessons.md` のC)
