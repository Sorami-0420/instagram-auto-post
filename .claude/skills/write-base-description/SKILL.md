# BASEの商品説明文を書く手順

商品名が決まったあとに、BASEに載せる説明文を書く。公開済みの商品は、「サイズ/重さより上の部分だけ」と頼まれることがある(そのときは、そこまで)。

## 先に聞くこと(分からないものは◯にして出し、確認する)
- サイズ(金具を含まない縦×横)と重さ。重さは**片耳**が基本(「金具抜き」と言われたときは、片耳かを確認する)
- 石の名前と大きさ(mm)。石の名前はそらみさんの言葉が正本。**写真から石や素材を決めつけない**
- 素材: ワイヤー・金具・飾りパーツ。金属アレルギー対応かどうか(対応していないものは、注意書きを入れる)
- 金具: 見本の写真に番号がある。「写真のとおり」と書き、1枚目の写真の金具の番号を、形状の選択の下に入れる(例: 「1枚目の写真は、⑭の金具を使用しています。」)
- 染めた石・樹脂などの処理は、素材の欄に(染め)などと入れる
- 撮影場所の言葉(冒頭の情景に使う。そらみさんが意図した言葉なので、そのまま使う)

## 石言葉・意味(必ずWeb検索で確かめる)
- 検索で複数の記事に出てくる石言葉だけを、「〜と言われています」の伝聞で書く。断定しない
- 見つからなかった石の意味は、書かない(例: ヘソナイト・マグネサイト)。近い石の意味を当てはめるときは、「ガーネット」のように、確認できた範囲の名前でまとめる
- 効果をうたう言い方(「〜を高める」「運気が上がる」)は入れない。入れるなら、紹介として「〜とも紹介されています」
- モチーフの言い伝え(コウモリは「福」と同じ発音で縁起がよい、など)も、検索で確かめる
- 染めた石は、元の石の意味を当てはめてよいか、そらみさんに判断してもらう(例: 赤く染めたサンゴ)
- 検索で確認できたこと/できなかったこと/推測を、返事で分けて書く。出典のリンクを付ける

## 文章の形(冒頭)
- 冒頭は、情景やモチーフを2〜3行で。そのあとに、石の説明を1まとまり。石言葉は1〜2文
- 商品は両耳用(2個で1ペア)。「一つ」「一粒」のように単品として書かない。ただし、BASEのサイズ/重さは片耳の書き方
- 「太陽」「月」は、モチーフから読み取れるときだけ
- 素材名は、冒頭の文では書かない(素材の欄で書く)
- 似た商品が並ぶときは、違い(ワイヤーのふわっと広がる形など)を冒頭に入れて、見分けがつくようにする

## 全文の型
```
(冒頭: 情景・モチーフ)

(石の説明・石言葉)

■サイズ/重さ
(金具を含まない本体サイズ)約◯×◯cm
(片耳)◯g
ピアス/イヤリングの形状はお好みに合わせて選べます。
(1枚目の写真は、◯の金具を使用しています。)

■素材
天然石...◯◯ ◯mm
ワイヤー…◯◯
金具…写真のとおり(または素材名)
※◯◯は金属アレルギー対応ではありません。

■適した浄化方法
月光・ホワイトセージ・水晶(クラスターやチップ)・音

■お手入れ/取り扱い注意事項
汚れが付いた場合は、柔らかい布で優しく拭いてください。入浴や海水での使用、また直射日光に当たる所での保管は石に良くないためお避けください。

■発送・注文に関する情報や注意事項
ご注文後、通常2～3日以内に発送いたします。非対面での発送サービスを利用し、安心してお受け取りいただける環境を整えております。万が一、不良品がございましたら、到着後7日以内にお知らせください。

■その他の情報や注意事項
一つ一つ手で作っているため左右には個体差があります。
```

## 石によって変える点
- 水・酸・乾燥に弱い石(オパール・マグネサイト・ハウライト・サンゴなど)は、浄化方法に水・酸を使わない(上の型のままでよい)
- サンゴなど、汗・香水・酸に弱そうな石は、お手入れの欄に1文を足す(例: 「汗や香水、酸性のものが付いた場合は、すぐに柔らかい布で拭いてください。」)。確認できていないことは、推測と分けて伝える
- 鉱物名が仕入れの表記と違っていた場合(例: ハウライト → マグネサイト)は、商品文・「使用石」列・石言葉の文を、すべて直す

## 返事の形
1. 全文を、コピーしやすいコードブロックで出す
2. 「検索で確認できたこと」「確認できなかったこと」を分けて書く
3. 「確認したい点」を、番号を付けて少数(◯の部分・金具・左右の違いなど)
4. 直したい箇所があれば、と聞く。修正のときは、直した部分だけを出す
5. 次の商品に進むか、聞く
