# 資料に残す手順

次の会話でも同じ間違いをしないよう、分かったことを資料に残す。

1. そらみさんに「資料に残します」と一言伝える
2. 書き先を決める
   - 間違いを防ぐ注意点 → `docs/claude-lessons.md`
   - 商品・方針・ルールの変更 → `docs/shop-info.md`
   - ID・アカウント情報 → `docs/private/ids.md`(公開リポジトリに入らないため。他のファイルには書かない)
3. 既存の項目に同じ内容がないか確認し、あれば更新する(重複して書かない)
4. 1項目を短く書く。注意点は「何が起きたか」と「どうすれば防げるか」を1行ずつ
5. 書いた内容を、そらみさんに1〜2行で報告する
6. コミット・pushは、そのつど「コミット・pushしてよいですか」と聞いてから。公開リポジトリなので、IDやキーは含めない
